# FollowCenter.ir
نسخه Demo چندصفحه‌ای پنل خدمات شبکه‌های اجتماعی.

## اجرا
فایل `index.html` را با یک وب‌سرور استاتیک باز کنید (برای مثال Live Server). همه صفحات از `style.css` و `script.js` مشترک استفاده می‌کنند.

## قیمت‌ها
تمام قیمت‌های پایه در ابتدای `script.js` داخل آبجکت `SERVICES` قرار دارند و قیمت بر اساس تعداد با فرمول `price * quantity / 1000` محاسبه می‌شود.

## ذخیره سفارش
سفارش‌ها با کلید `fc_orders` در LocalStorage ذخیره می‌شوند. برای نسخه عملیاتی باید Backend و Database جایگزین این لایه شوند.

## مرجع الهام
ساختار کلی از الگوی فروشگاه خدمات اجتماعی Shiraz Social الهام گرفته شده، اما متن، ظاهر، برند و پیاده‌سازی مستقل است. فقط چهار شبکه Instagram، Telegram، Rubika و Eitaa در این نسخه قرار گرفته‌اند.
